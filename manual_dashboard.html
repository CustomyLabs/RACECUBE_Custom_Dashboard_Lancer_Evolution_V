Руководство по аппаратному подключению RACECUBE

⚠️ ВАЖНОЕ ПРАВИЛО: Все модули, дисплеи, драйверы и сам микроконтроллер ESP32-S3 должны быть соединены по линии GND в одну общую сеть. Без общей массы система будет зависать по шине I2C или работать некорректно.

1. Шина I2C и питание логики (Шилды PCA9685 и PCF8575)

Питание логики микросхем подается отдельно от силового питания моторов. На шилдах PCA9685 контакт OE аппаратно притянут к земле, управлять им не нужно.

  • SDA (Данные): Пин 17 (ESP32) ➔ SDA (PCA9685) ➔ SDA (PCF8575)
  • SCL (Тактирование): Пин 18 (ESP32) ➔ SCL (PCA9685) ➔ SCL (PCF8575)
  • 5V (Логика): Пин 5V (ESP32) ➔ Пины 5V (на гребенках PCA9685) ➔ VCC на PCF8575
  • GND (Логика): Пин GND (ESP32) ➔ Пины GND (на гребенках PCA9685) ➔ GND на PCF8575

2. Питание шаговых моторов (PCA9685)

Зеленые клеммники питают исключительно катушки моторов. Питать их от USB или пина 5V самой платы ESP32 категорически запрещено.

  • V+ (Зеленая клемма): К автомобильному DC-DC преобразователю 5V (от 5 Ампер и выше).
  • GND (Зеленая клемма): К минусу того же DC-DC преобразователя.

3. Подключение и логика работы логометров (шаговых моторов)

Приборная панель использует двухфазные шаговые двигатели (типа VID29, Switec X27.168). Каждый мотор состоит из двух независимых катушек (SIN и COS), для работы которых требуется 4 контакта.

  • Аппаратное подключение: Каждый мотор подключается строго к 4 подряд идущим ШИМ-каналам на платах расширения PCA9685. Например, шкала №0 займет каналы 0, 1, 2, 3 на первой плате; шкала №1 займет каналы 4, 5, 6, 7 и так далее.
  • Логика работы (микрошаг): ESP32 использует предрассчитанную таблицу синусов для плавного позиционирования стрелки через ШИМ-сигнал.

4. Подключение CAN-модуля (VP1050)

  • TX (Передача): Пин 7 (ESP32) ➔ TXD (VP1050)
  • RX (Прием): Пин 4 (ESP32) ➔ RXD (VP1050)
  • Питание: Пин 5V и GND от соответствующих пинов ESP32.
  • CAN H / CAN L: К соответствующим проводам OBD2/CAN шины автомобиля.

5. ВЫХОДЫ: Подключение LED-ламп к модулю PCF8575

Чип PCF8575 имеет выходы типа «открытый сток» (он втягивает ток). Питание на светодиоды подается постоянно от линии 5V, а модуль замыкает их катод (-) на массу для включения света.

[ +5V от DC-DC ]
       │
[ Резистор 1 кОм ]  <-- Ограничивает ток
       │
[ + Анод (длинная ножка LED) ]
  СВЕТОДИОД
[ - Катод (короткая ножка LED) ]
       │
[ Пин P0...P15 на модуле PCF8575 ]

Распиновка портов PCF8575:
P0: Лев. поворот | P1: Прав. поворот | P2: Габариты | P3: Ближний | P4: Дальний
P5: Масло | P6: Check Engine | P7: Перед. ПТФ | P8: Задн. ПТФ | P9: Дверь
P10: Ручник | P11-P14: Универсальные лампы

6. ВХОДЫ: Считывание физических сигналов автомобиля (Оптопары)

⚠️ КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО: Подавать автомобильные 12V-14.4V напрямую на пины ESP32. Микроконтроллер сгорит мгновенно. Максимальное напряжение на пинах ESP32 — 3.3V!

Для безопасного чтения сигналов фар, поворотников, дверей используйте модуль опторазвязки (PC817 12V to 3.3V). Он обеспечивает полную гальваническую развязку.

Схема подключения входов:

[ Провод 12V от фары/поворотника ] ➔ [ IN+ канала оптопары ]
[ Масса кузова авто ]            ➔ [ IN- канала оптопары ]

[ Пин 3.3V ESP32 ]               ➔ [ VCC логики оптопары ]
[ Пин GND ESP32 ]                ➔ [ GND логики оптопары ]
[ Свободный GPIO пин ESP32 ]     ➔ [ OUT канала оптопары ]
Свободные пины ESP32-S3 для входов: Рекомендуемые пины для оптопар: 1, 2, 3, 5, 6, 8, 9, 15, 16, а также пины с 35 по 48.

7. Настройка ламп в WEB-интерфейсе

Параметр Описание и применение
Источник данных CAN / ESP-NOW — Данные из цифровой шины или по воздуху.
Цифровой Пин — Чтение физического пина. Для опторазвязки!
Аналоговый Пин — Чтение через АЦП (для резистивных датчиков).
Номер Пина ESP32 Укажите номер GPIO, к которому подключена оптопара (например, 5). Для CAN оставьте -1.
Порог АЦП Только для режима "Аналоговый Пин" (0-4095). Лампа горит при превышении порога.
Инверсия сигнала Модули опторазвязки инвертируют сигнал (выдают LOW при 12V на входе). Если лампа работает наоборот, выберите Да (Сигнал НИЗКИЙ = ВКЛ).

8. Настройка логометров в WEB-интерфейсе

Параметр Описание и применение
Поправка Нуля (градусы) Смещение начальной позиции. Выравнивает стрелку на нулевую отметку циферблата.
Рабочий угол (градусы) Максимальный угол шкалы (обычно 270 или 315). Защищает мотор от заворота.
Множитель (Scale) Коэффициент корректировки. Например: 0.95 для занижения на 5%. По умолчанию 1.0.

RACECUBE Hardware Connection Guide

⚠️ IMPORTANT RULE: All modules, displays, drivers, and the ESP32-S3 microcontroller MUST be connected via a common GND line. Without a shared ground, the system will freeze on the I2C bus or behave erratically.

1. I2C Bus and Logic Power (PCA9685 & PCF8575 Shields)

Logic power must be supplied separately from the motor power. The OE pin on the PCA9685 shields is hardware-pulled to ground, no need to control it.

  • SDA (Data): Pin 17 (ESP32) ➔ SDA (PCA9685) ➔ SDA (PCF8575)
  • SCL (Clock): Pin 18 (ESP32) ➔ SCL (PCA9685) ➔ SCL (PCF8575)
  • 5V (Logic): Pin 5V (ESP32) ➔ 5V header pins (PCA9685) ➔ VCC (PCF8575)
  • GND (Logic): Pin GND (ESP32) ➔ GND header pins (PCA9685) ➔ GND (PCF8575)

2. Stepper Motor Power (PCA9685)

The green terminals only power the motor coils. DO NOT power them from USB or the ESP32's 5V pin.

  • V+ (Green terminal): To an automotive DC-DC 5V step-down converter (5A or more).
  • GND (Green terminal): To the minus of the DC-DC converter.

3. Stepper Motor (Gauge) Connection & Logic

The dashboard uses 2-phase stepper motors (VID29, Switec X27.168). Each motor consists of two independent coils (SIN and COS) requiring 4 pins.

  • Hardware: Each motor connects to 4 consecutive PWM channels on the PCA9685 boards. (e.g., Gauge 0 uses ch 0, 1, 2, 3).
  • Logic (Microstepping): ESP32 uses precalculated sine tables to send exact PWM signals via I2C for smooth needle positioning.

4. CAN Module Connection (VP1050)

  • TX (Transmit): Pin 7 (ESP32) ➔ TXD (VP1050)
  • RX (Receive): Pin 4 (ESP32) ➔ RXD (VP1050)
  • Power: 5V and GND pins from the ESP32.
  • CAN H / L: To the respective OBD2/CAN bus wires of the car.

5. OUTPUTS: LED Indicators to PCF8575

The PCF8575 chip has open-drain outputs (it sinks current). Supply constant 5V to the LED anode, and the module will sink the cathode (-) to ground to turn it on.

[ +5V from DC-DC ]
       │
[ 1 kOhm Resistor ]  <-- Current limiting
       │
[ + Anode (long LED leg) ]
  LED DIODE
[ - Cathode (short LED leg) ]
       │
[ Pin P0...P15 on PCF8575 module ]

PCF8575 Pinout:
P0: L Turn | P1: R Turn | P2: Parking Lights | P3: Low Beam | P4: High Beam
P5: Oil | P6: Check Engine | P7: Front Fog | P8: Rear Fog | P9: Door Open
P10: Brake | P11-P14: Universal Aux

6. INPUTS: Reading Physical Car Signals (Optocouplers)

⚠️ STRICTLY PROHIBITED: Do not supply automotive 12V-14.4V directly to ESP32 pins. The microcontroller will burn instantly. Max voltage for ESP32 pins is 3.3V!

To safely read headlights, turn signals, and door switches, use a PC817 12V to 3.3V optocoupler board for full galvanic isolation.

Input Connection Diagram:

[ 12V wire from car signal ] ➔ [ IN+ of optocoupler channel ]
[ Car body ground (Chassis) ]➔ [ IN- of optocoupler channel ]

[ 3.3V Pin from ESP32 ]      ➔ [ VCC logic of optocoupler ]
[ GND Pin from ESP32 ]       ➔ [ GND logic of optocoupler ]
[ Free ESP32 GPIO pin ]      ➔ [ OUT of optocoupler channel ]
Free ESP32-S3 Input Pins: Recommended pins for optocouplers are 1, 2, 3, 5, 6, 8, 9, 15, 16, and 35 through 48.

7. WEB Interface: Lamp Setup

Parameter Description
Data Source CAN / ESP-NOW — Data from digital bus/wireless.
Digital Pin — Reads physical pin state. Use this for optocouplers!
Analog Pin — ADC read (for resistive sensors).
ESP32 Pin Number The GPIO connected to the optocoupler (e.g., 5). Leave at -1 for CAN.
ADC Threshold Only for "Analog Pin" mode (0-4095). Lamp turns on when voltage exceeds this value.
Signal Inversion Most optocouplers output LOW when 12V is applied. If the lamp works in reverse, select Yes (LOW Signal = ON).

8. WEB Interface: Gauge Setup

Parameter Description
Zero Offset (degrees) Adjusts the starting position so the needle perfectly aligns with the '0' mark on your dial.
Working Angle (degrees) The total sweep of your printed dial (usually 270 or 315). Prevents the motor from pushing past the limit.
Multiplier (Scale) Adjustment factor. For example, 0.95 reduces the reading by 5% (useful for speedometer correction). Default is 1.0.
